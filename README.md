# Klere landing page

Marketing site for **Klere**, the iPhone app that decodes a child's IEP in plain language, privately, with Apple Intelligence and Private Cloud Compute.

Plain static HTML and CSS, no build step.

- `index.html` — the page
- `styles.css` — styles (tokens match the app's `Theme.swift`)
- `assets/` — app icon

## Preview locally

```bash
python3 -m http.server 8000
```

Then open http://localhost:8000.

## Before launch

Replace the bracketed placeholders in `index.html`: `[APP STORE LINK]`, `[PRIVACY POLICY URL]`, `[SUPPORT URL]`, `[CONTACT EMAIL]`, `[YEAR]`, `[YOUR COMPANY NAME]`.
